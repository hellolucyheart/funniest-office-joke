One short joke about office life, in a single line of at most 200 characters: the elevator has been "out of order" so long that facilities put a plant in it — and now it's the only meeting room with natural light.

## Run it

```sh
python3 main.py
```

It validates the line (one sentence, 1–200 characters) and writes it to `/output/entry.txt`.
